# Notícias do Mercado

Área semanal para conectar os conceitos das trilhas com acontecimentos reais.

## Modelo de atualização

Para cada notícia:

1. O que aconteceu?
2. Que conceito da trilha aparece aqui?
3. Quem ganha e quem perde?
4. O que muda para o investidor?
5. Que pergunta isso gera para discussão?
