# Scripts de manutenção

Scripts usados **uma única vez** para corrigir problemas pontuais: acentos quebrados, alinhamento de aulas, links, rodapé e outros. Ficam aqui como histórico.

- Eles **não** fazem parte do site e não rodam sozinhos.
- Vários usam caminhos relativos à raiz do repositório. Se precisar rodar um deles de novo, execute a partir da raiz, por exemplo `python scripts/manutencao/check_encoding.py`, e leia o código antes, porque alguns alteram arquivos.
